# Moroz'Co — демо сайта

Сайт производителя замороженных домашних полуфабрикатов **Moroz'Co**: пельмени, вареники, манты, хинкали, котлеты, долма, голубцы, блинчики, сырники.

Чистые HTML/CSS/JS без сборки — работает на GitHub Pages или любом статическом хостинге.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: баннер-слайдер, преимущества, популярная продукция, «как заказать», о компании, форма для опта |
| `catalog.html` | Каталог: фильтр по категориям (`catalog.html#manty`), поиск, сортировка, карточка товара во всплывающем окне |
| `about.html` | О компании: история, цифры, производство, принципы |
| `contacts.html` | Контакты, форма обратной связи, карта |
| `crm/` | **Панель заявок** — сюда приходят заказы и заявки с сайта в реальном времени |

## Как работают заявки

1. Покупатель кладёт товары в корзину и оставляет имя и телефон (маска `+998 (XX) XXX-XX-XX`).
2. `assets/js/lead.js` отправляет заявку во все каналы из `assets/js/config.js`:
   - **ntfy.sh** (включён по умолчанию) — бесплатный канал уведомлений. Его слушает панель `crm/`; на телефон заявки можно получать через приложение ntfy, подписавшись на тему из `config.js`.
   - **Вебхук CRM** (`webhookUrl`) — POST с JSON заявки. Сюда подключается «настоящее» приложение для заявок.
3. Панель `crm/` показывает новые заявки сразу, со звуком и уведомлением браузера. Статусы (новая / в работе / выполнена / отменена) хранятся в браузере менеджера.

> Тема ntfy видна в коде сайта, поэтому прочитать заявки может любой, кто её знает. Для демо это нормально, для рабочего сайта нужен свой сервер или вебхук CRM.

- `assets/js/config.js` — телефоны, почта, адрес, координаты карты, ссылки на Telegram/Instagram.
- `assets/js/data.js` — товары, цены, вес, состав. Картинки — SVG-иллюстрации в `assets/img/products/`; можно заменить на фото (4:3, webp/jpg), поменяв поле `img`.
